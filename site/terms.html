1. Status of this draft

MILAAN is an early-stage GST invoice reconciliation project. The legal entity operating the service is [To be confirmed]. These terms describe the current demo and must be updated when a production service is launched.

2. What the demo provides

The public demo is a local evaluation environment that uses synthetic records. It is not a production service, does not have a service-level commitment, and may change or become unavailable without notice.

The demo demonstrates invoice validation, normalized GSTR-2B import, deterministic reconciliation, discrepancy classification, supplier follow-up drafting, approval records and audit history. It is intended for evaluation, not for live tax processing.

3. No tax, legal, filing or recovery service

MILAAN is not a tax adviser, chartered accountant, filing intermediary or recovery service. It does not file GST returns and does not connect to a government filing system.

Reconciliation results are aids for review. A missing match does not prove supplier non-filing, establish input tax credit eligibility or guarantee recovery. You remain responsible for verifying records and obtaining appropriate professional advice before acting.

4. Using the demo

  • Use synthetic records in the public demo.
  • Do not upload real taxpayer, supplier or personal data unless you have authority to do so and a reviewed data-handling arrangement is in place.
  • Do not attempt unauthorized access, disrupt the demo, introduce malicious code or use the demo unlawfully.
  • Do not rely on demo output for a tax filing, payment, recovery claim or supplier dispute.

5. Data and privacy

The demo stores records in a SQLite database. Uploaded rows, validation outcomes, reconciliation results, drafts and audit events may be persisted on the machine running the demo. The project does not claim application-level encryption at rest.

See the Privacy Policy for the current draft description of data handling. Retention, deletion, processor and contact details require confirmation.

6. Availability and changes

The demo is provided on an “as available” basis. There is no promise of uptime, support, data preservation or continued availability. Features and these terms may change as the project develops.
